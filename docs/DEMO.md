# 5분 시연 순서

`deploy/demo.sh up`(또는 로컬 개발 모드 + `uv run python -m app.seed`)으로 띄우면 데모 센터 "햇살방문요양센터(가상)"와 계정, 그리고 **김순자(가상)의 2주 가상 이력**이 준비돼 있습니다. 모든 인물과 기록은 가상입니다. 비밀번호는 모두 `demo1234`.

| 이력 | 일어난 일 |
|---|---|
| 13일 전 | "오른쪽 무릎이 시큰거린다" → 다음에 무릎 다시 확인 |
| 10일 전 | 무릎은 비슷하다(이전 확인 결과), 손녀가 다음 달에 온다 → 손녀 방문 날짜 확인 |
| 6일 전 | "계단 내려갈 때 무릎이 아프다" → **7일 안 두 번째 무릎 불편 = 변화 알림** |
| 3일 전 | 기운이 없다, 점심 조금 → **식사량 감소 알림**, 손녀 방문 날짜 확인 결과 |
| 2일 전 | 밤에 무릎 통증으로 잠을 설침(긴급 우려) → 센터가 진료 예약 후 보호자에게 안내 |

## 1. 요양보호사 (`demo`) — 2분

1. **김순자(가상)** → 방문 전 확인 화면
   - 맨 위 **변화 알림** 2건: 근거 날짜를 누르면 원래 기록으로 간다 (AI가 아니라 확정된 값으로 서버 규칙이 만든 알림)
   - **남은 확인 사항**, **주의 항목**, **후속 확인 완료율**(기획안의 품질 지표), **식사량과 기분** 추이
   - **요약 만들기** → 문장마다 "근거 날짜" 링크가 달린 AI 인계 요약
2. **방문 시작** → **오늘 방문 기록하기**
   - 녹음 전 고지 확인 → 1분 녹음(또는 음성 파일). 예: "오늘 어르신이 무릎은 좀 나아졌다고 하셨어요. 점심은 절반 정도 드셨고, 식사량은 다음에도 볼게요."
   - **검토 화면**: AI 초안에 근거 구절(형광펜)이 붙고, 누르면 그 구간부터 재생. 이전 확인 사항("식사량 다시 확인")에 대한 답도 AI가 근거와 함께 제안. 오늘 상태(식사량·기분)와 불편 부위
   - 전부 확인 → **확정하기**
3. **방문 종료**

## 2. 기관 담당자 (`manager`) — 2분

1. 홈의 **센터 관리** → **알림 인박스**: 무릎 불편 반복·식사량 감소. 처리 메모와 함께 **조치함/오탐**. 보호자 안내를 쓰면 받을 보호자를 열람 범위를 보고 고른다
2. **확인 대기** 기록 → 읽고 **센터 확인 서명**
3. 확정 기록 화면의 **보호자 하루 요약** → 만들기 → 문장 고치기 → **승인하고 보호자에게 공유**
4. 수급자 화면의 **담당 배정 · 동의 · 보호자 관리**: 동의 기록·철회, 보호자 열람 범위, **기록 내보내기(CSV)**와 **열람·정정·내보내기 이력**

## 3. 보호자 (`family`) — 1분

- **센터 안내**(담당자가 고른 보호자에게만), 방문 시각, 방문별 **센터가 확인한 하루 요약**
- 열람 범위가 "말씀, 다음 확인"이라 관찰 문장("점심을 조금만 드심")은 요약에서도 빠져 있다
- 전사문·음성·근거 구절·요양보호사 이름은 보이지 않는다

## 덧붙여 보여 줄 만한 것

- 확정 기록의 항목을 **정정**(사유 필수) → 정정 이력, 무릎을 허리로 고치면 무릎 반복 알림이 "정정으로 닫힘"
- `demo2`로 로그인하면 배정된 수급자가 없다 → 기관 담당자가 배정하면 바로 보인다(담당 교체 시연)
- 품질 평가 결과: [docs/eval/README.md](eval/README.md)
